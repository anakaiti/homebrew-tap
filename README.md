# Anakaiti Tap

## How do I install these formulae?

`brew install anakaiti/tap/<formula>`

Or `brew tap anakaiti/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "anakaiti/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
